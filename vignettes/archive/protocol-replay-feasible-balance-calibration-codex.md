# Protocol-Replay Feasible Balance Calibration

This memo proposes a non-collapsing calibration for covariate balance in
matched observational studies. It responds to the failure mode in which the
within-set randomization standard punishes tighter matches because the null
covariance of the balance statistic shrinks toward zero.

The core proposal is a protocol-replay feasible balance calibration with an
absolute tolerance gate. It treats matching as a design procedure, not as a
treatment-assignment null.

## The Problem

In the Hansen-Bowers omnibus balance test, the balance statistic has the form

```text
T = d' V_d^+ d,
```

where `d` is the vector of within-set adjusted treated-minus-control mean
differences and `V_d` is the covariance of `d` under treatment
re-randomization within the realized matched sets.

That reference distribution is local to the realized sets. As matching tightens,
the within-set spread of the covariates shrinks. Consequently,

```text
within-set var(X) -> 0
V_d -> 0
```

and, for fixed residual imbalance `d0`,

```text
d0' V_d^+ d0 -> infinity.
```

The reported balance can therefore get worse as the matched design gets tighter.
That is not a coding bug. It is the meaning of the within-set reference: the
observed residual imbalance is being judged against a reference distribution
that has collapsed around zero.

## Proposal

Before scoring balance, define a complete design protocol `P`. The protocol must
include:

- the eligible treated and control pools;
- the covariates, transformations, and interactions used for design assessment;
- the exact-match strata;
- the matching ratio and replacement rule;
- the discard rules;
- the caliper grid;
- the distance metrics and covariate weights;
- the candidate matching algorithms;
- the tuning rule;
- the final selection rule;
- an explicit probability law `Q_P` over full matched-design search paths.

The last item is essential. The reference distribution is not "whatever sampler
is convenient." It is part of the method. Different probability laws over
candidate matched designs can produce different calibrations.

Fix a pool-scale covariance matrix `Sigma0`, computed once from the eligible
pool, and a practical balance tolerance

```text
c = r delta^2,
```

where `r = rank(Sigma0)` and `delta` is the largest acceptable RMS standardized
imbalance. The value of `delta` is a scientific adequacy threshold, not something
estimated from the final match.

Run `P` on the real covariates `X` to obtain the realized matched design
`M_obs`. Define the fixed-scale balance loss

```text
L_obs = d(M_obs)' Sigma0^+ d(M_obs).
```

The first report is a tolerance gate:

```text
PASS if L_obs <= c
FAIL otherwise.
```

The gate prevents an optimized design from receiving a favorable percentile
while still having scientifically unacceptable absolute imbalance.

Conditional on passing the tolerance gate, draw full design paths

```text
U_b ~ Q_P,  b = 1, ..., B,
```

and replay the same design protocol on each path. Each replay keeps treatment
labels, units, covariates, and structural constraints fixed. What varies is the
matched-design search path allowed by `P`, not treatment assignment.

For each replay, record the selected matched design `M_b` and its loss

```text
L_b = d(M_b)' Sigma0^+ d(M_b).
```

Report the high-good protocol-replay feasible percentile

```text
PRFP = (1 + number of b with L_b >= L_obs) / (B + 1).
```

Interpretation:

```text
Among matched designs generated by the same predeclared design protocol,
the realized design is better balanced than about 100 * PRFP percent of them,
on the fixed pool scale, after passing the absolute balance tolerance.
```

Optionally, report a search-efficiency ratio

```text
SER = (mu_P - L_obs) / (mu_P - L_best_P),
```

where

```text
mu_P      = E_{Q_P}[L_b],
L_best_P = infimum loss attainable under the same protocol class.
```

If `L_best_P` cannot be computed exactly, report an interval for `SER` using
certified optimization bounds. Do not report a single value when the bound is too
loose to be meaningful.

## Why This Does Not Collapse

The collapse in the within-set test comes from the term `V_d^+`, where `V_d` is
computed from the realized matched sets. This proposal does not use that
covariance.

Consider a sequence of tighter matched designs with

```text
within-set var(X) -> 0
```

but fixed residual mean imbalance

```text
d(M_obs) -> d0.
```

Because `Sigma0` is fixed from the eligible pool,

```text
L_obs -> d0' Sigma0^+ d0,
```

which is finite. The tolerance gate therefore stays fixed:

```text
L_obs <= c
```

does not become harder merely because within-set variance shrinks.

For fixed `P`, fixed `Q_P`, fixed `Sigma0`, and fixed `c`, the protocol-replay
reference distribution does not shrink around the realized matched sets. It is a
distribution over analogous matched-design paths. Therefore

```text
PRFP -> Pr_{Q_P}{ L_b >= d0' Sigma0^+ d0 },
```

not zero. If the fixed-scale imbalance improves, so that `L_obs` decreases, then
`PRFP` weakly increases for a fixed reference distribution. Likewise, if
`mu_P > L_best_P`, then

```text
d SER / d L_obs = -1 / (mu_P - L_best_P) < 0,
```

so improved fixed-scale balance improves `SER`.

The load-bearing condition is that `P`, `Q_P`, `Sigma0`, and `c` are fixed before
balance scoring. If those move, the benchmark moves too, and monotonicity is no
longer guaranteed.

## Trilemma Trade

This method sacrifices the within-set standard. It does not re-randomize
treatment within the realized matched sets.

It also relaxes the requirement that the assessment compare only to the exact
design the analyst built. The comparison class contains analogous matched
designs that could have been built under the same predeclared protocol.

That is the necessary trade. The within-set standard is the source of the
collapse. A non-collapsing calibration must change the reference distribution.
Here the new reference is still design-respecting because every reference draw
uses the same pool, treatment labels, covariates, structural constraints, and
matching protocol.

## What This Is Not

This is not an `l*` or resolution-profile method. It does not merge matched sets,
sweep over coarsenings, use progressively larger randomization blocks, or report
a crossing point.

This is not complete randomization. Treatment labels are never permuted over the
whole pool. The randomized object is the matched-design search path.

This is not a treatment-assignment test. It is a calibrated design-quality
assessment.

This also differs from Branson's design-as-null framework. Branson assesses
assignment mechanisms implied by candidate designs and places designs on a
fixed-Sigma Mahalanobis scale. Here, the fixed metric defines the loss, but the
calibration comes from replaying an analogous matched-design protocol.

## Overfitting And Search

The main threat is not that the analyst found a very balanced match. That is the
point of matching. The threat is that the analyst searched over procedures,
calipers, distances, covariate transformations, or discard rules, then reported a
calibration that ignores that search.

Protocol replay handles this only if `P` includes the whole search:

```text
If the analyst tried five specifications and selected the best one,
each reference replay must try the same five specifications
and apply the same selection rule.
```

If the search history is incomplete, the honest report is a sensitivity analysis
over protocol scope. For example, report `PRFP` under increasingly expansive
protocols:

```text
P_1: final matching recipe only
P_2: final recipe plus caliper search
P_3: final recipe plus caliper, distance, and discard search
P_4: all recorded specifications
```

A design whose favorable calibration disappears under a plausible broader
protocol should not be described as strongly balanced. It should be described as
sensitive to design search.

## Computation

One loss evaluation is cheap once `Sigma0^+` has been computed:

```text
O(n p)   to compute d(M)
O(p^2)   to evaluate d' Sigma0^+ d
```

The expensive step is replaying the design protocol. With `B` reference draws,
the cost is roughly

```text
B * cost(one protocol replay).
```

For pair matching, possible replay mechanisms include randomized assignment
solves, randomized minimum-cost bipartite matchings, or switch-chain samplers
that preserve calipers and exact strata. For full matching or variable-ratio
matching, randomized network-flow procedures are more appropriate.

Bad sampling can dominate the answer. The memo's recommendation is therefore not
"sample somehow." The probability law `Q_P` and its implementation must be
documented. When Markov chains are used, report mixing diagnostics or sensitivity
across starting points and proposal kernels.

For the optional `SER`, computing `L_best_P` may require a hard integer or
network-flow optimization. If the optimum cannot be certified, report bounds.

## Falsification Plan

A simulation meant to detect hidden collapse must hold the reference fixed. It
should not change calipers or feasibility rules across the tightening sequence
unless those changes are already inside the fixed protocol `P`.

One useful design is:

1. Generate a treated and control pool with overlapping multivariate normal
   covariates.
2. Fix one broad protocol `P`, including its caliper grid, candidate algorithms,
   tuning rule, final selection rule, and probability law `Q_P`.
3. Fix `Sigma0` and `c`.
4. Construct a sequence of realized matched designs within the same protocol
   class whose within-pair distances shrink.
5. In one branch, hold the fixed-scale residual imbalance approximately
   constant.
6. In another branch, let the fixed-scale residual imbalance improve.
7. For each design, compute the within-set Hansen-Bowers percentile, `L_obs`,
   the tolerance gate, `PRFP`, and `SER`.

Expected behavior:

```text
Within-set variance decreases.
The within-set Hansen-Bowers calibration can worsen.
When L_obs is fixed, PRFP and SER stay stable.
When L_obs improves, PRFP and SER improve.
```

The method fails if `PRFP` or `SER` systematically worsens while `L_obs` is fixed
or improving and `P`, `Q_P`, `Sigma0`, and `c` are held fixed.

A second verification checks the forbidden comparison. Every reference draw must
preserve treatment labels, matched structure, exact strata, ratios, calipers, and
discard rules. If the reference distribution can be reproduced by complete
treatment-label randomization of the pool, the implementation is wrong.

## Limitations

The method is conditional on the protocol. If `P` is vague, post-hoc, or missing
parts of the design search, the calibration is not credible.

The tolerance `c` is a scientific judgment. That is not a defect by itself, but
it must be visible. A percentile without an absolute tolerance can call the least
bad feasible design excellent. The gate prevents that.

The reference distribution is only as good as `Q_P`. A poorly mixed sampler, a
sampler that ignores important constraints, or a sampler that places mass on
scientifically irrelevant matched designs will give a misleading percentile.

The method assesses observed covariate balance. It does not test hidden bias and
does not certify causal identification.

The hardest objection is practical: real design work is exploratory. Analysts
often change the protocol after seeing balance diagnostics. Protocol replay
requires that exploration to be recorded and replayed. Without that record, the
method can still be used as a sensitivity analysis, but not as a clean calibrated
assessment.

## Bottom Line

The cleanest non-collapsing path is to stop asking whether the observed residual
imbalance is surprising under treatment re-randomization within the realized
matched sets. That reference collapses as matching tightens.

Instead, ask whether the realized matched design passes a fixed-scale balance
tolerance and, conditional on that, where it falls among analogous matched
designs generated by the same predeclared protocol. This changes the question,
but it changes it in the right direction: from a collapsing within-set
randomization standard to a design-quality calibration over feasible matched
designs.
